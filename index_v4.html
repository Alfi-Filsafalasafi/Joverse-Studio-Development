Cara Order

Alur Pemesanan.

Delapan langkah sederhana dari join Discord hingga project mulai dikerjakan.

1

Masuk ke Discord Joverse Studio

Join server resmi kami untuk memulai proses order.

2

Masuk ke Kategori Payment Joverse

Temukan channel khusus order di dalam server.

3

Klik "Create Ticket"

Buka tiket order pribadi untuk didampingi Developer.

4

Pilih Layanan yang Ingin Diorder

Contoh: Map Roblox, System, Building, Rekber, Bug Fix, Asset.

5

Diskusikan Project Bersama Developer

Jelaskan kebutuhan, referensi, dan detail project kamu.

6

Developer Memberikan Quote Harga

Harga final ditentukan berdasarkan faktor penentu harga.

7

Lakukan Pembayaran

Bayar sesuai metode yang tersedia dan kirim bukti transaksi.

8

Project Mulai Dikerjakan

Developer mulai mengerjakan project sesuai kesepakatan.

+

+

Bisa. Kamu bebas request tema sesuai kebutuhan project, harga akan menyesuaikan tingkat kompleksitas tema.
